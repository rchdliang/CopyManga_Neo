# CMP 画质修复

## 平台与模型

CMP Android、Windows 和 Linux 共用 Vulkan compute 后端，执行 Anime4K 的同尺寸修复，不增加输出分辨率。iOS 和 Web/Wasm 暂无后端，保留原图并显示不可用。独立 Android 项目不接入此方案。

固定上游为 [Anime4K](https://github.com/bloc97/Anime4K/tree/7684e9586f8dcc738af08a1cdceb024cc184f426)。Restore 与 RestoreSoft 各有 S、M、L、VL、UL 五个网络，分别包含 4、8、9、17、25 个计算阶段。它们是不同规模的网络，不是给同一张图重复锐化。原始 GLSL、权重、许可证及来源摘要保存在 `native/reader-restore/models`；构建时改写纹理绑定包装并编译为随包分发的 SPIR-V，不修改训练权重。

旧 waifu2x 路径与 Android GLES 修复后端已移除，无运行时模型下载。旧版本已经下载的缓存不自动删除，也不继续参与运行或打包。

## 设置与调节

- 模式按钮组为“关 / Restore / RestoreSoft”，默认关闭。
- 滑块有 S、M、L、VL、UL 五档；关闭时不可调。Restore 与 RestoreSoft 分别记忆档位，默认 M。
- 模式、最后使用的模式与两组档位写入全局 `reader-tools.json` 并进入设置备份；旧数据缺少字段时使用默认值。
- 调节面板直接显示当前漫画页的处理结果，无需另按预览。只有进入面板时自动放大一次：分页阅读最大 5 倍，连续阅读最大 3 倍。
- 进入后可以继续缩放、拖动。切换模式或档位、处理完成、点击“完成”或关闭面板都不重置用户调整的位置和缩放。布局替换视图时转移当前视图状态，不再次放大。
- 宽屏使用侧边面板，窄屏使用底部面板；调节时连续阅读暂时停用列表翻页，将拖动用于查看当前图。

锐化仍为默认关闭、0–100%、5% 一格；修复开启时不叠加锐化。最高锐化强度和最大修复网络均不代表最佳画质。漫画小字、网点、细线与白边的效果仍需真实图片判断。

## 数据流与资源

复用 Coil 已加载静态图 → 内存 RGBA 副本 → Vulkan 分块上传和多阶段计算 → RGBA 读回 → Compose 显示。没有临时图片文件或 PNG 编解码往返，但仍有 CPU 内存复制与 GPU 上传、读回成本，不是零拷贝。

每块有效区域为 256×256，边缘重叠按网络采样范围计算；中间特征使用有符号 RGBA16F，输入和最终输出为 RGBA8。图像边缘按全图边界采样，拼块仅写入有效区域。串行工作线程复用设备、队列、管线及缓冲，最多缓存两组模型资源。

输入限于不透明 sRGB 静态图，最多 4,194,304 像素、单边最多 16384。超预算或不支持的图像保留原图，不静默降低分辨率。结果按源图身份、generationId、页面和模式/档位缓存，最多两份输出、总输出预算 32 MiB；源图、GPU 资源和仍被绘制引用的旧结果另计。静态显示不重复计算。

切换参数后等待 150 毫秒合并快速操作，再异步处理最新请求；分块之间检查取消和会话代次，过期结果不得替换当前图。关闭修复并退出调节、进入后台或离开活动路由会释放缓存与 GPU 资源；关闭阅读会话释放线程。驱动调用不能被协程硬中断。

设备必须支持所需 Vulkan 图像格式及资源限制。缺少驱动、设备不支持或处理失败时保留原图并报告状态，不自动改用 CPU 推理。软件 Vulkan 只在验证程序显式启用，正式应用不选择 CPU Vulkan 设备。

Android 从应用库目录加载 JNI。桌面先校验随包库的 SHA-256，再以文件锁和原子替换提取至 `~/.cache/copymanga-neo/reader-restore-runtime/<摘要>` 并加载。该目录仅存运行库；修复图像不写磁盘、不覆盖下载、导出、历史或书签。

## 构建与验证边界

构建工具和任务见 [构建说明](BUILDING.md)。`native/reader-restore/verify_outputs.py` 使用原始权重的 NumPy 参考计算核对十组网络，包含跨分块边界与图像四边。`VulkanBridgeProbe.java` 通过正式 JNI 与桌面资源加载器检查 JVM/Native Image 链路。软件 Vulkan 可验证计算结果，但不能代表 Linux 硬件性能。

共享测试覆盖五档控件、独立档位持久化、关闭禁用、只在进入时自动放大、手动位置保持、缓存与位图变更失效。Android APK 编译及桌面计算验证不能替代 Android 真机驱动兼容性、Linux 硬件运行或完整 Native Image 安装包验收。

设备验收应检查真实漫画页的小字、细线、网点、白边与锯齿，记录首张及缓存后的耗时、连续阅读流畅度和内存，并检查快速切换、翻页取消、后台释放与恢复。当前实现不保证 Vulkan 在所有设备上更快，也不以构建成功证明画质收益。
